# Speaker guide

Use this guide to prepare for any Universe on the Road 2026 session.

## Session resources

Each session folder under [`sessions/`](sessions/) contains:

| Resource | Description |
| --- | --- |
| `deck/presentation.pptx` | Presentation deck: latest approved slides |
| `speaker-guide.md` | Speaker guide: narrative, talking points and timing |
| `transcript.md` | AI transcript: full reference transcript |
| `demo-prep.md` | Demo preparation: setup, validation and fallback |
| `README.md` | Session overview, demo code link, and pre-presentation checklist |

## Before presenting

- [ ] Review the session speaker guide and latest deck
- [ ] Verify product announcements and talking points
- [ ] Run the demo preflight
- [ ] Check for [city-specific changes](shared/city-notes.md)
