# Security

## Scope

This repository contains Universe on the Road 2026 session resources. Security concerns include exposed credentials, sensitive information, or vulnerabilities in code and demos hosted here.

For vulnerabilities in an externally linked project, follow that project's security policy. For vulnerabilities in GitHub products or services, use [GitHub's security reporting guidance](https://docs.github.com/en/site-policy/security-policies/coordinated-disclosure-of-security-vulnerabilities).

## Report a concern privately

Do not disclose vulnerabilities, credentials, or sensitive information in public issues, pull requests, or discussions.

If private vulnerability reporting is enabled, open the repository's **Security** tab, select **Report a vulnerability**, and submit a private report. See [GitHub's private reporting instructions](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

If that option is unavailable, contact a repository maintainer privately to arrange a secure reporting channel before sharing details.

Include:

- The affected file, demo, or resource.
- A description of the concern and its potential impact.
- Safe reproduction steps, if applicable.
- Suggested remediation, if known.

Do not include live secrets or unnecessary personal data in a report. If you own an exposed credential, revoke or rotate it immediately; deleting it from a file does not invalidate it or remove it from Git history.

## Updates

Security fixes to resources maintained in this repository should target the current default branch. This resource center does not define a versioned support schedule or guaranteed response time.
