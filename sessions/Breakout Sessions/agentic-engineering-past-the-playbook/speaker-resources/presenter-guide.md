# Speaker Guide: Agentic Engineering Past the Pilot — An Enterprise Playbook

**GitHub Universe on the Road 2026**

## Session overview

This session explores how enterprises can move beyond isolated AI coding pilots to adopt agentic engineering across the entire software development lifecycle.

Through a practical scenario, attendees will see how GitHub Copilot, cloud agents, and automated workflows help teams plan, build, verify, and deliver software faster.

**Core message:** AI has dramatically accelerated code generation, but enterprise productivity depends on improving the entire software development process. Agentic engineering connects planning, development, verification, and delivery into a unified workflow.

### Before you present

- Review the presentation deck and AI session summary for additional talking points.
- Familiarise yourself with the GitHub Copilot app, cloud agents, agentic workflows, and automated verification.
- Review and rehearse the demonstrations embedded in the PowerPoint.
- Understand the differences between traditional development workflows and the agentic approach demonstrated.
- Prepare for the audience participation at the beginning of the session.

## Session flow

### 1. Setting the scene: The productivity gap (Slides 1–15)

- Begin with the interactive quiz comparing GitHub commit volumes year over year.
- Highlight the dramatic increase in code generation and development activity.
- Ask whether developers actually feel proportionally more productive.
- Explain how the bottleneck has shifted from writing code to reviewing, verifying, and delivering it.
- Introduce the new GitHub flow: **Plan, Build, Verify, and Observe**.

### 2. From traditional planning to agentic workflows (Slides 16–29)

- Introduce the 4th Coffee scenario, comparing traditional development planning with an agentic approach.
- Highlight the time lost gathering context, creating issues, and coordinating work manually.
- Show how Copilot uses meeting transcripts, business data, and observability insights to help refine requirements.
- Demonstrate how Copilot creates tracking issues and agentic workflows automatically triage and assign work.

### 3. Planning and specifications with Copilot (Slides 30–40)

- Introduce the GitHub Copilot app as a central place to manage development work.
- Demonstrate how developers can turn issues into structured plans and specifications using `/plan` and `/spec`.
- Emphasise human collaboration and approval of plans before implementation.
- Highlight how agentic workflows reduce planning and coordination from days to hours.

### 4. Building with parallel cloud agents (Slides 41–49)

- Explain how cloud agents can work on multiple tasks simultaneously in isolated environments.
- Demonstrate managing multiple agent sessions through the Copilot app.
- Show how developers can continue working across devices, including mobile.
- Introduce **Cloud Sandboxes, Memory, Dreaming, and Fusion**.
- Emphasise how agents preserve context and collaborate across the development process.

### 5. Automated verification and delivery (Slides 50–62)

- Explain why verification becomes increasingly important as agents generate more code.
- Introduce **stacked pull requests** to make large changes easier to review.
- Highlight GitHub Code Quality and Copilot code review for automated quality checks.
- Introduce AI security scanning, secret detection, license compliance, and Agentic Autofix.
- Demonstrate how Agent Merge helps address failing checks, review comments, and merge conflicts.
- Emphasise that automation should accelerate delivery without compromising quality or governance.

### 6. The enterprise playbook (Slides 63–66)

- Bring the full workflow together: **Plan → Spec → Build → Verify → Deploy**.
- Reinforce the importance of connecting context, approving intent, and applying consistent governance.
- Encourage teams to adopt cloud agents and embed AI into verification, not just coding.
- Highlight how automation helps enterprises scale agentic engineering across teams.
