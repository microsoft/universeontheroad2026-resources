# Keynote — Presenter Resources

Presenter resources for the **GitHub Universe on the Road 2026 opening keynote**.

The opening keynote sets the scene for the event, highlights the key themes from GitHub Universe, and introduces the Product Updates session that follows. There are no demos in the opening keynote. Product demonstrations take place during the Product Updates session.

## 1. Learn the presentation

1. Read the slides and speaker notes from start to finish.
2. Understand the event narrative, key announcements, and transitions.
3. Rehearse the **20-minute opening keynote**, including the transition to Product Updates.

## 2. Deliver the keynote

- Follow the event run of show and agreed presenter handoffs.
- Keep the messaging aligned with the shared presentation.
- Confirm any location-specific welcome, acknowledgements, and event details.
- Test the slides and presenter display on the venue equipment.
- **Do not plan a live demo.** Introduce the Product Updates session as the place attendees will see the announcements demonstrated.

## 3. Hand off to Product Updates

Close with a clear transition: the opening keynote has introduced the themes and announcements; the **Product Updates session immediately afterward will show the products and capabilities in action through demos**.

Coordinate the final slide and speaker handoff with the Product Updates presenter so the transition feels seamless.
