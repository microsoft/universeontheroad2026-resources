# Ask the Experts — Presenter Resources

## About the session

Ask the Experts is a 35-minute interactive Q&A session where attendees can ask GitHub experts questions about the latest GitHub Universe announcements, enterprise adoption, AI-powered development, security, and governance.

Unlike traditional breakout sessions, there is no presentation or formal demo. The conversation should be driven by audience questions and real-world challenges.

## Session format

**Duration: 35 minutes**

- **Introduction (2 minutes):** Introduce the experts and their areas of expertise.
- **Audience Q&A (30 minutes):** Invite questions and encourage discussion.
- **Wrap-up (3 minutes):** Summarise key themes and direct attendees to relevant resources.

### Presenter guidelines

- Prioritise questions from the audience.
- Keep answers practical, concise, and relevant to enterprise scenarios.
- Encourage experts to share real-world examples and lessons learned.
- Invite different perspectives from the panel.
- Be transparent about product limitations, availability, and roadmap commitments.
- Use the suggested questions below if audience participation slows.

## Suggested discussion questions

These questions are inspired by GitHub Universe 2026 announcements and common enterprise challenges. They are intended to help start conversations, not replace audience questions.

### 1. Moving beyond the AI pilot
**What should enterprises prioritise when moving from GitHub Copilot pilots to agentic engineering at scale?**

How do organisations move beyond individual developer productivity and improve the entire software development lifecycle?

### 2. Agent governance
**How should enterprises approach governance as AI agents gain more autonomy?**

What policies, permissions, approval processes, and controls should organisations establish before allowing agents to work independently?

### 3. Measuring success
**How should enterprises measure the value and ROI of GitHub Copilot and AI agents?**

Should teams focus on adoption, developer productivity, pull request throughput, code quality, or completed business outcomes?

### 4. Copilot Automations
**Where should organisations start with Copilot Automations and agentic workflows?**

Which repetitive engineering tasks deliver the most immediate value, and how can teams introduce automation without sacrificing control?

### 5. Context and collaboration
**How can organisations provide AI agents with the right context across repositories, teams, and tools?**

How do capabilities such as Copilot Memories, custom instructions, and connectors help agents understand enterprise development practices?

### 6. Security in an agentic SDLC
**How does security need to evolve as AI agents generate and modify more code?**

How can GitHub Advanced Security, AI scanning, Copilot code review, and Agentic Autofix help organisations maintain security at scale?

### 7. Model selection and cost management
**With multiple AI models available, how should enterprises balance performance, cost, and governance?**

What role can Copilot Fusion and enterprise AI usage controls play in managing model selection and consumption?

### 8. The future of code review
**As agents generate more pull requests, how do we prevent code review from becoming the next major bottleneck?**

How can stacked pull requests, automated code review, and Agent Merge help teams deliver changes safely and efficiently?
