# Support

## Session resources

For missing recordings, broken links, documentation errors, or questions about resources hosted here, search the repository's existing issues first. If no issue covers your question, open a new one.

Include the session title, the affected file or URL, what you expected, and what happened. For problems running a demo, include relevant reproduction steps and environment details. Remove credentials, personal information, and confidential data from logs or screenshots before sharing them.

Resources marked "Coming soon." are not yet available. This repository does not promise publication dates or support response times.

## Contributions

To submit a correction or add a resource, follow [contributing.md](contributing.md).

## Security concerns

Do not report security concerns publicly. Follow the private reporting guidance in [security.md](security.md).

## GitHub product and account support

This repository is not a support channel for GitHub account, billing, or product issues. Use [GitHub Docs](https://docs.github.com/), [GitHub Community](https://github.com/orgs/community/discussions), or [GitHub Support](https://support.github.com/) as appropriate. For service availability, check [GitHub Status](https://www.githubstatus.com/).

For an externally linked demo or project, use its own documentation and support channels.
